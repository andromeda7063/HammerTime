## Supplied FastF1 cache and offline baseline — 2026-10-31

Added an explicit cache importer and a separate `supplied_fastf1_monza_2023.yaml` configuration. The importer checks all destination hashes before copying, aborts on conflicting content, skips identical files, rejects symlinks and active SQLite WAL/SHM sidecars, and leaves the source cache untouched. The supplied archive was imported to `hammertime_100/data/cache/supplied-fastf1/2023-Monza-R/`; the existing default race cache has a different HTTP-cache database and was preserved. An offline load through the imported cache reproduced the Italian Grand Prix 2023 Race session with FastF1 3.8.3: 957 lap rows, 20 drivers, 719,620 car-telemetry rows, and 746,600 position rows. FastF1 exposes position telemetry as `pos_data`.

Offline preprocessing produced 348,384 aligned rows (329,577 valid), 19 represented drivers, 944 valid driver-laps, 18,336 graph snapshots, and 17,244 target labels. The FastF1 lap-accuracy check marked all laps for driver 22 inaccurate; the measured preprocessing coverage above includes the resulting source coverage. With the unchanged 10-frame window, five-frame horizon, 4 Hz grid, and 15-window purge per boundary, the temporal split has 7,855 train, 1,656 validation, and 1,672 test windows. The outcome-boundary diagnostic found 0/11,942 valid train outcomes crossing the validation input-start boundary and 0/2,513 valid validation outcomes crossing the test input-start boundary for this session and configuration. This observed result does not resolve possible cross-boundary outcomes in other sessions/configurations or whole-session clean-air reference leakage.
