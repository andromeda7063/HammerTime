INTERPRETATION

Read the limits

  • In-sample MAE is below the configured threshold (< 0.150 s); this is not a held-out result.
  • Inference covers recorded 2023 Singapore Grand Prix session features (Marina Bay Street Circuit).
  • The target is a full-session-calibrated residual, not a live-known delay estimate.
  • Safety-car periods (Lap 20 SC, Lap 44 VSC) are excluded from the inference windows.
